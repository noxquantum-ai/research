# Historical archive

This directory retains superseded project presentations, strategy documents, scorecards, and the chronological experiment log. The files are preserved so prior results, failed approaches, and original conclusions remain auditable. Legacy claims in these files may be outdated, speculative, or contradicted by later measurements; use the root README and experiment reports for the current position.

- `EXPERIMENT_LOG.md` is the chronological research record.
- `legacy/` contains the former root README, novelty and launch material, and the earlier multi-tier scorecard and reports.
- `legacy_strategy/` contains superseded project plans and broad speculative analysis.
- NEC experiment reports are organized under `docs/experiments/`.

Repository-relative links in archived material may refer to the original file layout. Conclusions and result values have not been rewritten as part of this archive move.
