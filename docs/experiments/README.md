# NEC experiment reports

These reports document the experiments and measured baselines that inform NEC’s current compression objective. They are research records, not claims that an accuracy-preserving high-compression method has been found.

- `function_aware_tn/` covers exact representation symmetries, Schmidt-spectrum analysis, function-aware baselines, and the queued Llama-2-7B diagnostic.
- `grouped_swiglu_tn/` contains the joint SwiGLU, operator-Schmidt, rank-bound, and quality-first grouped-TN results.
- Machine-readable results and run logs remain under `experiment_artifacts/`.
