I did not use the MPO representation for the final 32-layer artifact.

I extended the Nox codebase with a second codec path and selected it because the experiment showed the existing MPO path was decisively dominated.

### Final approach

For every Q, K, V, O, Gate, Up, and Down matrix:

sⱼ=clamp(RMS(Xⱼ)^{0.5},0.1,10)

Then:

1. Scale each input channel: W_{:,j}sⱼ
2. Quantize row-local groups of 64 weights to packed symmetric 3-bit codes
3. Store the packed codes, FP16 group scales, and FP16 channel scales
4. Reconstruct with Ŵ_{:,j}=Q₃(W_{:,j}sⱼ)/sⱼ

The activation statistics come only from 1,024 pinned WikiText training tokens propagated through the dense model. There are no gradients or updates after serialization.

### What changed in the engine

- Added nox/residual_codec.py (nox/residual_codec.py) with genuine 2/3/4-bit packing and exact byte accounting.
- Extended reconstruct_from_artifact() so the existing Nox loader dispatches legacy MPO, MPO plus residual, or direct packed artifacts.
- Extended checkpoint injection so the same evaluation path loads the new codec.
- Added scripts/compile_direct_packed.py (scripts/compile_direct_packed.py), which constructs all 32 layers atomically and stores the complete model footprint.
- Preserved the original NEC/MPO compiler unchanged.

### Why MPO was not selected

The matched experiment found:

- Two-layer NEC: PPL 9.442, 139.85 MB
- Direct packed 3-bit: PPL 5.323, 164.66 MB
- NEC plus 2-bit residual: PPL 5.665, 253.84 MB

So the hybrid used 54% more bytes than direct 3-bit and was less accurate.

The tensor-cut diagnostic also found the rank-128 MPO discarded roughly 80–93% of the activation-preconditioned residual energy at important cuts. That is a representation-capacity limit, not something another cross-layer correction can fully repair.

So this result is a Nox engine extension and an evidence-based representation change, but it is not an MPO compression victory. It shows that, for these projections, conventional packed activation-aware quantization currently preserves substantially more model intelligence per byte than NEC’s MPO representation.
