The initial layer-0 diagnostic is complete on the A10. I used the repo’s A10-mvc1exyr_key.pem with mode 600, cloned main at 786409e, and reused the saved high-fidelity layer-0 checkpoint. No prefix recompilation, PPL, MMLU, or full-model run was done.

The MLP is the main failure source: restoring all dense MLP projections reduced block relative error from 0.364 to 0.188; restoring attention reduced it only to 0.343. I tested the redesign only on Gate and Up. Their held-out projection errors improved substantially, but the new MPO core added only a small improvement beyond sparse + bridge (0.0019 for Gate, 0.0053 for Up). The Gate/Up candidate reduced full-block error only from 0.364 to 0.348. Its two core counts were slightly lower, but the serialized layer checkpoint shrank by just 33,729 bytes. The candidate run took 17.83 seconds and peaked at about 7.83 GiB GPU memory.

I recommend not spending more GPU time on layer-prefix or full-model runs yet. The evidence points to the Gate/Up/Down interaction as the unresolved problem, and this independent-projection redesign barely improves block behavior.
