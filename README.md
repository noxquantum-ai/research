# Nox research

Nox is exploring algorithms that let pretrained AI models run with less memory and hardware while preserving useful behavior. The first research question is whether ideas from quantum information, including tensor networks, can improve the quality, memory, and inference latency tradeoff beyond strong quantization and matrix factorization methods.

Start with the [research brief](RESEARCH_BRIEF.md) for the current evidence and technical hypothesis, then use the [three-week experiment plan](EXPERIMENT_PLAN.md) to run the first study. These are working documents, dated 2026-10-02. No experimental result or novelty claim has been established yet.

The broader vision is to build an algorithm research company from Africa. The [African Union's Continental AI Strategy](https://au.int/sites/default/files/documents/44004-doc-EN-_Continental_AI_Strategy_July_2024.pdf) notes that most African countries lack advanced GPU resources in universities and research institutions. This motivates the deployment constraint, but the first technical claim must stand on reproducible measurements.
